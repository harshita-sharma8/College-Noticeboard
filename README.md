# College-Noticeboard
The College Notice Board System (CNBS) is a lightweight, responsive web-based CRUD application developed using PHP, MySQL, HTML, CSS, and JavaScript.

---

## Features

- **Dynamic CRUD Operations:** Create, Read, Update, and Delete notices effortlessly.
- **Categorization & Filtering:** Organize notices by academic branch, year, or topic.
- **Responsive Dashboard:** Card-based UI for seamless view across desktop and mobile screens.
- **Relational Database:** Robust MySQL backend structure for fast queries and data integrity.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP (Native)
- **Database:** MySQL
- **Server Environment:** XAMPP / Apache
